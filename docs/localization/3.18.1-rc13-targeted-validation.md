# 3.18.1-rc.13 定向修复与验收

本候选基于本地 rc.12 提交 `f4d777a14e08fc2be17e68ebc43a88fa73ad1357`，
保留上游 Qt5/C++17 3.17.2 标识。内容变化递增为 `rc.13`，不是正式稳定版。
该文件记录准备范围，不表示新程序、七个包或发布验收已经通过。

## 本轮改动

- 普通启动直接打开同目录主程序，取消每次启动的语言选择窗口。
  首次采用系统界面语言，已存偏好优先，主窗口菜单仍可选择并在重启后生效。
  `--language` 仅对当前会话生效；保留 `--launch`、参数分隔符、工作目录和退出码。
- 修复 Windows 许可通知测试夹具的缺失输入，按原字节校验随包文本。
- 修复 Linux 工作流重复的 `container` / `defaults` 配置。
- UI 验收支持显式指定独立构建的版本记录，三种语言及图片导出均使用隔离配置。
- 新增独立的本地精确 SHA256 插件身份来源，不授予 CI 路径豁免；
  旧记录继续保留，未知或变化的二进制仍须重新审查。

## 测试顺序与范围

遵循用户 2026-11-13 的新要求：不再进行全量测试，只测试新增功能及可能受影响的回归。
每个候选先完成所有可执行的选定测试、汇总失败与明确未执行项，
之后集中修补并构建下一候选。不会因单个失败中断独立检查。

本轮覆盖语言决策与保存、默认启动与参数转发、外置版本记录、
Windows 许可夹具、精确二进制身份和隐私、版本与包清单，
以及少量 CSV/APBIN 数据入口、布局与主窗口语言切换。
不重复运行未变化图片的完整 107 项渲染、全部解析器/数学测试，
也不重复构建 ON/OFF 两套配置来替代风险判断。

发布仍需七个软件包对应同一受验源码，安装/解包启动、三种语言、
数据入口、包体身份、隐私、必要许可、对应源码和可用重链接材料通过核对。
实际静态 LGPL 交付准备见 [重链接材料说明](relinking-3x.md)。
候选未通过的门槛不得通过删断言、冒称 CI 或借用旧候选成绩来消除。

## 保留限制

150%/200% 缩放、小窗口和 IFW 所有页面全面汉化暂不作为完整支持承诺；
普通显示范围内的核心控件必须可用。繁体图库沿用英文原图，
外部插件、服务器和用户数据中的原始文字可能仍为英文。
保留旧测试证据与现有发布，不覆盖旧标签、资产、用户配置或 4.x 安装。
