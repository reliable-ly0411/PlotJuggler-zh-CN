# rc.2 后续修复（开发中，未发布）

基线为开发线 `203d29a8`；其树与已发布 rc.2 源码 `09487081`、稳定线一致。
本变更不修改已发布标签、附件或历史 Release 说明，不启用发布或上游自动更新。

## 变更与验收边界

- Windows 主程序为 GUI 子系统，启动不分配新控制台；继承父控制台或已重定向的
  stdout/stderr，保留 CLI、插件和 Python 诊断。由原 SVG logo 生成多尺寸 ICO 并嵌入 PE。
  CI 对实际 PE 检查子系统及 RT_ICON/RT_GROUP_ICON，并验证重定向输出。
- About 指向 `PlotJuggler/PlotJuggler`；帮助菜单分别提供汉化和上游问题入口。
- `-zh` 构建直接检查汉化仓同主版本发布列表，比较汉化修订/rc 序号；只提供手动下载，
  不运行无远程仓库的 IFW，不建议添加上游 APT 仓库，也不使用上游安装器覆盖汉化。
- 中文启动图尊重 memes/serious 设置，新增经审阅的 8 组双格中文趣图，使用现有无文字哭猫/胜利小孩底图和 Qt 可翻译排版，不覆盖或遮挡英文像素。
  这 8 组是额外创作。原 37 张逐图清单现有 33 张可用（31 张中文像素版本、2 张仅含产品/技术名的原图），
  与额外 8 组组成 41 项中文池。09/11/13/24 尚不可用，明确排除，不能声称原 37 张全部完成。
  英文原池保持原样；逐图来源与像素验收见 `resources/memes/PIXEL_REVIEW.md`。
- 全市场固定目录 30 项的名称和描述均有展示翻译，Windows 平台可用 29 项；这不是
  默认随包数量（Windows 19 / Linux 21）。英文搜索和 canonical IDs、URL、协议不变。
  Mosaico 市场描述翻译；其原始二进制内部剩余英文仍属既有例外。
- 同版本随包本地重建采用真实 DSO SHA256 身份和精确旧构建来源锁，先安全迁移再扫描。
  未知用户替换和后续市场更新保留，成功 receipt 防止每次启动重复覆盖。
- IFW >=4.10 支持 `--lang`，候选工具链固定 4.10.0。显式嵌入标准页中文和 QtBase 字典，
  目录选择前提供中文/English 重启式切换；默认目标 ASCII 目录和显示名含 zh-CN。
  实现及限制见 [安装器说明](../../packaging/installer/README.zh-CN.md)。

全源码提取和翻译检查通过。这些单测不等于 Windows GUI 验收。

## 资源体积边界

原 37 张英文 JPEG 合计 2,713,369 字节，保持原样。新增 31 个中文 PNG/atlas 文件
合计 36,550,977 字节（约 34.86 MiB），不做有损重编码；这不是最终安装包增量。
Qt 大资源构建避免生成数百 MB 的 C++ 字节数组，不以关闭资源或删图规避内存限制。
Linux Qt 6.11.1 实测资源对象 37,035,208 字节；仅调整 rcc 无损压缩阈值即可比默认
节省 4,693,200 字节，全部 281 项资源读回字节与源文件相同。该对象大小不是 Windows EXE 或安装包大小。
最终主程序字节数由 Windows PE CTest 输出；最终完整安装包尚未重建，不能把资源
源文件大小或 synthetic fixture 大小当成实际安装包大小。
