本机缺 CMake、Qt、Xvfb 与 xdotool，未执行现代双平台 C++ 编译、Qt lupdate 源覆盖或成品包验收。本合并不发布新包，不继承正式版通过结论；后续应在已配置 Ubuntu 和 Windows VM 针对本合并提交执行全量原生与包验收。

## Ubuntu 复核后的集中修复

Ubuntu 对合并提交实际运行 774 个方法：739 通过、32 跳过、3 个失败方法，并且真实 Xvfb 已运行，不能与云端缺工具混淆。Qt 6.12 严格提取发现两语各缺 6 条（4 条正式版插件加载诊断、2 条新上游 MCP 提示）。本次集中补齐两语目录至 2,113 条并加逐键回归。

三个方法分别修复：CMake 诊断换行仅在断言比较时归一空白（符号守卫本身已拒绝不安全导出）；workflow fixture 补真实 picker 审计脚本及完整 4 用例和坏报告拒绝回归；X11 解析修正重复扣除 border 的实际生产错误。xwininfo 已以 `(-border,-border)` 平移输出 outer 原点，因此左上不应再减 border，右下须由 client size 加两侧 border。真实窗口预期 `(8,8,1583,955)` 保持不动，并补 0/1/3/8 像素边框及右下越界用例。

修复后仍需 Ubuntu 对新提交重跑 CMake 执行测试、严格 lupdate 和真实 Xvfb；不启动大型编译，不占用 3.18.1 的 Windows VM。以上不是新成品包验收结论。
