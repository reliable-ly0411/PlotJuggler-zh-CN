## 整合要点

保留上游 QRhi 渲染、异步数据集合并、新数据源/场景/派生对象逻辑，迁移中文显示层，
不覆盖回旧架构。保留 #33 的 FFT 显示映射、插件元数据和紧凑面板可见性回归；
接纳新的 Widget 插件类型。保持配置、曲线和插件的 canonical ID，保留独立测试配置。

HTTP 下载统一入口保留上游限制/超时行为和明确的中文翻译上下文；URL 模型缓存仍服从
隔离配置目录。新增 SDK 接口对应的测试 API 与独立配置测试依赖一起更新。
RHI/模型诊断采用明确翻译上下文，目录提取兼容 Qt 解析器对局部 using 的限制。
简体和繁体目录分别包含 2,091 条有效 Qt 可提取消息；这不等于所有可见文案或任意插件均已翻译。

稳定线专属 source-sync/Qt5 手动验证配置保留原有门禁。新增的官方 conda/macOS 工作流
在本地化线保持手动运行，conda 发布步骤只允许官方仓库身份，避免同步源代码时意外发布。
纯上游镜像不混入这些本地化策略。
