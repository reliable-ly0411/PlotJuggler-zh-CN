# Embedded Python host hook boundary

rc.16 AppImage audits rejected `usr/lib/python3.10/sitecustomize.py` on both
architectures because the stdlib copy preserved an absolute link to
`/etc/python3.10/sitecustomize.py`. Its link-text SHA256 is
`82a38efc36075379bdddaabdb2a6d8e9835e1960b25977872532dc9c005e3223`.

The source was checked against the actual Ubuntu Jammy package version used by
that run, `3.10.12-1~22.04.18`, independently for both architectures:

- https://archive.ubuntu.com/ubuntu/pool/main/p/python3.10/libpython3.10-minimal_3.10.12-1~22.04.18_amd64.deb
  SHA256 `ccbd08562769e0a38b34005dc8bde200838e6c6530cc04ac34525129ed42d847`
- https://ports.ubuntu.com/ubuntu-ports/pool/main/p/python3.10/libpython3.10-minimal_3.10.12-1~22.04.18_arm64.deb
  SHA256 `f3ef036c6b8ab24a2785ee70854b1fe5217e6e24d2d3e8aa36d9404e7d89b6eb`

Each package's `etc/python3.10/sitecustomize.py` is 155 bytes, SHA256
`43d81125d92376b1a69d53a71126a041cc9a18d8080e92dea0a2ae23be138b1e`.
It only conditionally imports `apport_python_hook` and installs its exception
handler when available. Ubuntu documents this host crash-reporting mechanism:
https://ubuntu.com/project/docs/contributors/debugging/apport/

A self-contained embedded runtime must not import arbitrary host `/etc`
customization. Packaging now verifies both that exact link and exact official
source bytes before omitting this optional host Apport hook. Changed contents,
unknown targets and non-regular sources fail closed. This is not a general
sitecustomize exclusion: `site.py`, sysconfig, the configuration tree and all
package scans remain. An omission receipt is retained in acceptance evidence.
No other symbolic link policy is relaxed.

Unit checks cover both architecture layouts, retained configuration contents,
changed/unknown source rejection and source symlink rejection. Actual rebuilt
AppImage inventory and runtime checks remain required for release.
